Introduction: The Engineer Who No Longer Types

In late 2025, Boris Cherny, the creator and head of Claude Code at Anthropic, made an observation that would have sounded like science fiction just three years earlier. He had not manually written a single line of code since the previous November. Instead, he described what he wanted, Claude Code figured out how to build it, ran the tests, fixed the failures and shipped pull requests. He was running five local terminal sessions and five to ten remote instances concurrently, shipping ten to thirty pull requests per day [1].

The creator of the tool is describing how the company that built it actually operates every day and this is only one data point in a much larger story.

As of May 2026, more than 80 percent of the code merged into Anthropic’s own production codebase was authored by Claude, up from low single digits before Claude Code launched in research preview in February 2025 [7]. The engineers at Anthropic do not type out implementations from scratch. They describe what they want, Claude Code figures out how to build it, runs the tests, fixes the failures and ships the pull requests. The human engineers review the output, make architectural decisions and move on to the next problem [8].
