Questions

Do I need to know how to program?

No. The book starts from what a program is and how to run one. You need a computer where you can install Python, or a browser to use Python online.

What happens after the free lessons?

The third lesson ends with a link to buy the rest. If you don't, the emails simply stop.

Can I read faster than one a day?

Yes. Every lesson has a "Send the next one now" button.

Can I pause?

Yes, from a link in any email. The course waits and picks up exactly where you left off.
